# 米字格練字

給孩子在 iPad 上練寫中文字的網頁小程式，用 Apple Pencil 或手指都可以。

- **描紅**：每個字先示範筆順，再在紅色米字格裡沿著灰色的字描。爸爸媽媽按住「家長評分」給 0–5 顆星。
- **聽寫**：孩子只看到拼音，自己把字寫出來。電腦給筆順分和結構分，對錯由家長批改。
- **家長設定**（按住 1 秒）：輸入要練的字或要聽寫的詞，簡體或繁體都可以；字體可選香港繁體、台灣繁體或簡體。

所有記錄只存在使用者自己的瀏覽器裡，不會上傳。
